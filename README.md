# TIC-TAC-TOE 

This is a simple Tic-Tac-Toe game that I developed as a mini project to practice my **HTML, CSS, and JavaScript** skills.

The game is played between two players on a 3×3 grid. Players take turns placing **X** and **O**, and the player who gets three symbols in a row wins the game.

## Features

* Two-player gameplay
* Win and draw detection
* Simple and clean interface
* Restart game option
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Start playing.

## What I Learned

Through this project, I practiced JavaScript logic, DOM manipulation, event handling, and basic frontend design.
